# CEDAR ELEVATORS - PHASE 1 FEATURE DECISION MATRIX
**Document Version:** 1.0  
**Status:** Read-Only Analysis Complete  
**Classification Guide:**  
- **P1_ACTIVE**: Required for Phase 1 customer or admin experience. Must remain visible and operational.  
- **P2_DEFERRED**: Not required for Phase 1. Preserved in codebase and database, hidden or redirected from UI.  
- **INTERNAL_DEPENDENCY**: Shared background library, table, or service required by an active feature. Must not be broken.  
- **RETIRE_CANDIDATE**: Obsolete, duplicate, or superseded legacy code requiring explicit removal approval.
